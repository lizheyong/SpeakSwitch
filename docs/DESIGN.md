# 界面设计记录

声选 · SpeakSwitch 是「语音输入切换器」，使用 macOS 原生窗口、侧栏和控件，围绕“快速选中当前语音工具”组织界面。主窗口、菜单与切换提示跟随系统深浅色外观，使用系统字体、语义颜色和强调色。

## 系统外观

窗口使用 `windowBackgroundColor` 和系统分组表单背景。正文与说明使用 `primary`、`secondary`，选中状态与图表使用系统强调色。标题、正文、说明和数字均使用系统字体角色，快捷键使用系统等宽字体。

产品页面由原生控件决定背景、边界、选中与按压反馈。品牌图形的底板和墨色定义在绘制代码内，页面不依赖品牌调色板。

## 麦克风回转箭头标识

标识由麦克风和沿托架向上回转的箭头组成，表达语音输入与切换。应用图标使用浅灰圆角底板与石墨色符号，菜单栏使用同一轮廓的单色模板图。几何定义在 `Sources/VoiceSwitch/BrandMark.swift` 的 `BrandMarkGeometry`。中文名为「声选」，英文名为「SpeakSwitch」，副标题为「语音输入切换器」；One Fn 保留为功能说明。

坐标基准为 1024 × 1024，原点位于左上，Y 轴向下。

| 元素 | 基准值 |
| --- | --- |
| 圆角底板 | `(100, 100, 824, 824)`，圆角 186 |
| 麦克风 | `(446, 248, 132, 314)`，圆角 66，实心填充 |
| 托架与箭头描线 | 52，圆头、圆角连接 |
| 符号墨迹范围 | `(296, 248, 488, 568)` |
| 箭头顶点 | `(702, 400)`，两侧端点 `(646, 456)`、`(758, 456)` |
| 支架底边 | 从 `(442, 790)` 到 `(582, 790)` |

应用内 `BrandMark` 使用这组几何等比绘制，并按墨迹范围居中。`BrandStatusIcon` 将同一符号置于 18pt 画布内，最长边为 16pt；模板图由 macOS 提供菜单栏明暗与选中颜色。

`scripts/make-icon.swift` 生成 `.icns`，使用相同的麦克风和托架路径，底板带轻渐变与阴影。绘制上下文统一使用左上原点，菜单栏图使用 flipped 画布。修改标识时同步应用内几何与图标脚本，检查大图、32px 小图和 18pt 菜单栏的方向与可读性。

## 主窗口与任务布局

默认窗口为 940 × 700pt，最小为 760 × 560pt，使用标准标题栏。窗口通过 `NSHostingController` 托管主视图，使用 `.fullSizeContentView` 和统一工具栏，保留系统安全区。`NavigationSplitView` 的侧栏为原生 `List`，宽度范围 180–250pt，默认 200pt；导航依次为“输入法”“使用统计”“共享词库”“接入指南”“设置”。启用 Fn 开关与状态固定在侧栏底部。

- “输入法”使用分组 `Form`，依次显示当前应用、已接入应用、更多输入法和添加操作。当前应用只展示图标、名称、就绪状态和 Fn / Shift + Fn 说明。
- 应用行保留真实图标、名称、用户备注和配置操作。选择、接入与获取按实际安装和配置状态显示。
- 接入弹窗为 580 × 600pt，中间使用可滚动的分组表单，确认、取消和保存固定在底部。语音输入与可选翻译分别录制快捷键；保存及选用成功后关闭弹窗，失败时保留错误信息。
- 设置页使用原生开关、权限按钮和键值行；接入指南按步骤分组。
- 菜单栏默认仅显示标识。在设置中启用“菜单栏显示当前输入法名称”后，图标右侧显示当前输入法名称；此选项保存在应用配置中。悬停提示包含当前输入法和 Fn 状态。
- 菜单栏使用真正的 `NSMenu`，显示状态、已接入应用及当前勾选、启用或暂停、打开窗口、接入助手和退出。应用条目带 16pt 系统应用图标，选择应用时保持原输入窗口焦点。

## 四步接入助手

`Sources/VoiceSwitch/OnboardingView.swift` 使用 580 × 540pt 的原生表单弹窗。顶部展示步骤与进度，中间滚动，底部固定“稍后设置”“上一步”和“继续 / 完成”。尚未接入且未选择稍后设置时自动显示，也可以从菜单栏或接入指南打开。

1. **选择输入法**：展示已安装应用的真实图标和接入状态，支持重新检测与添加 `.app`。未安装应用的官网入口放在折叠区域。
2. **允许系统权限**：分别展示辅助功能和输入监控的真实状态，提供系统设置入口。说明部分 macOS 将辅助功能称为“设备控制和数据访问”，以及声选不申请麦克风权限。返回应用时刷新状态，另提供手动检查和在 Finder 中定位当前应用的操作。
3. **设置快捷键**：打开所选应用的接入设置页，分别配置语音和可选翻译。保存快捷键后仍需进入真实 Fn 试用。
4. **试用 Fn**：准备目标应用并启用路由，提供临时练习输入区。用户亲自确认 Fn 开始、结束及文字上屏后勾选结果，才可完成。已就绪时保留“重新准备试用”，便于重新选择微信系统输入源等准备工作；故障说明按原快捷键、Fn 响应和上屏结果区分。

助手的步骤、所选输入法与确认状态保存在本机偏好设置，权限要求重启后可以继续。选择“稍后设置”关闭助手，保留已保存的应用设置；主动重开从选择输入法开始。切换输入法、修改快捷键或失去权限时清除试用确认。应用不录音、不记录其他应用中的键入内容。练习文字只在内存中临时显示，退出助手时清空，不参与自动成功判定。

接入设置页对已核实的应用给出具体步骤：

- Typeless 指向设置中的 Keyboard shortcuts，说明语音 `⌃⌥1`、翻译 `⌃⌘1`，并明确释放随便问的 `Fn + Space` 和其他附加 Fn 绑定。三个键包含修饰键与普通键。
- Chatterfly 直接打开设置应用，语音使用 `⌃⌥⇧`，指令模式的双击 Fn 改为 `⌥⇧⌘`。说明最多三个修饰键、一起按下后松开，以及 AI 指令与翻译的区别。
- 微信输入法打开安装包中的 `Contents/MacOS/WeTypeSettings.app`，指向“启动语音输入”，建议 `⌃⌥2`，说明其与“按住说话”的区别及系统输入源要求。
- 其他模板和自定义应用使用独立全局快捷键的通用说明，翻译须对应原应用实际提供的动作。

接入设置同时提醒释放其他常驻语音应用、系统 🌐 / Fn 动作和系统听写的 Fn 绑定。打开具体快捷键设置页时暂停 Fn 接管；可折叠的排查区域说明测试将延迟三秒发键、由原应用结束录音，关闭设置页后再试真实 Fn。测试前启动目标应用，为微信选择系统输入源。

## 切换提示 HUD

`Sources/VoiceSwitch/SwitchFeedback.swift` 提供短暂的切换反馈。选中应用后，鼠标所在屏幕顶部显示真实应用图标、名称与“已切换”；旁白同时播报应用名。

面板为 360 × 96pt，位于屏幕可见区域顶部中央，距可见区域顶边 4pt。面板使用非激活 `NSPanel`，不能成为 key 或 main window，也不接收鼠标事件。它可以随 Space 和全屏应用显示，保持原输入窗口的焦点。

内部提示使用系统 `regularMaterial`、14pt 圆角和轻阴影，文字跟随系统前景色。应用图标为 34pt，位于 40pt 图标区；名称为系统 15pt semibold，状态文字使用系统 subheadline。图标和名称共同表达切换结果。

每次展示后 1.6 秒开始淡出；常规淡入 0.16 秒、淡出 0.22 秒。连续切换复用同一面板、更新内容并重新计时。图标使用轻缩放和透明度过渡。系统开启“减少动态效果”时，保留短暂透明度变化。

## 使用统计

`Sources/VoiceSwitch/UsageView.swift` 使用分组表单，通过系统分段控件切换“今天 / 近 7 天 / 近 30 天 / 全部”，默认展示近 7 天，每 60 秒更新日期范围。

- 概览使用键值行显示“启动次数”“估算使用时长”“平均每次时长”，数字使用系统 headline 和等宽数字。
- 每日启动图使用 Apple Charts 和系统强调色，补齐无记录日期；悬停显示日期、次数和估算时长。“全部”的总量覆盖全部记录，每日图明确标为最近 30 天。
- 应用按估算使用时长排序，展示图标、历史名称、启动次数、听写与翻译次数、时长、时长占比和平均每次时长。细进度条辅助比较占比。
- 未完成和等待结束的次数分别呈现。统计只包含经 One Fn 发起的操作，以开始、结束操作配对估算时长；缺少结束的记录不计时长和平均值，也不把原应用确认的录音状态作为已知事实。
- 记录按开始当天归类，跨日配对的完整时长计入开始当天。空数据使用零值与明确空状态；记录保存在本机，不包含音频或转写文本。

## 词库与第三方图标

共享词库根页面通过 `GeometryReader` 接受 detail 列的可用宽高。顶部输入区使用按内容定高的原生 `Grid`，`Table` 在剩余高度内滚动，底部操作保持可见。共享词库使用系统输入框和双列表格，词语与备注分列，支持搜索、选择后编辑或移除、双击编辑、撤销移除、文件导入和导出。准备导入文件后，由用户在目标应用中确认导入。CSV 仅包含词语，JSON 备份保留备注；纠错替换规则由原应用管理。

`ProviderIcon` 优先读取已安装应用的系统图标，再读取内置产品图标资源；缺少资源的自定义应用使用系统应用图标。主列表、统计页与 HUD 共用该组件，原生菜单直接取得系统应用图标。第三方图标和商标权利归各产品权利人所有，来源见 [ASSETS.md](ASSETS.md)。
